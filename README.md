# WallScape - Profesjonalny Druk UV Na Scianach

## Struktura projektu
- index.html - Glowna strona
- css/styles.css - Style
- js/script.js - Logika strony
- js/content-loader.js - Ladowanie tresci z JSON
- content/*.json - Tresci edytowalne przez CMS
- admin/ - Panel CMS (Decap CMS)
- netlify.toml - Konfiguracja Netlify

## Wdrozenie
1. Stworz repo na GitHub: git init && git add . && git commit -m "init"
2. Polacz z Netlify (app.netlify.com)
3. Wlacz Identity + Git Gateway w Netlify
4. Skonfiguruj Formspree (zamien your-form-id)
5. Panel CMS: twoja-strona.netlify.app/admin
